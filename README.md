## 🔍 Overview

Ce repo Github contient un cours d'introduction à l'explicabilité des modèles de machine learning.

Ce cours est présenté en 2h et est accompagné de 8h de travaux pratiques.

## 🌱 Documentation

La documentation est générée avec [jupyter-book](https://jupyterbook.org/en/stable/intro.html).

Le cours est disponible sur la page github.io du repo :
https://thomasbouchecours.github.io/introduction_explicabilite/chapter/root.html
